# Consumer Goods SQL Analysis

## 📌 Project Overview

This project focuses on analyzing consumer goods business data using **MySQL** to answer real-world business questions and generate actionable insights.

The project was completed as part of the **Codebasics Resume Project Challenge**, using a simulated consumer electronics business scenario.

The analysis covers sales performance, customer contribution, product performance, pricing, manufacturing costs, and other business metrics.

---

## 🎯 Business Objective

The objective of this project was to use SQL to transform raw business data into meaningful insights that could support management decision-making.

The analysis was structured around ad-hoc business questions requiring:

* Data extraction and preparation
* Multi-table analysis
* KPI calculation
* Sales and customer analysis
* Product performance analysis
* Business-focused interpretation of SQL results

---

## 🗂️ Dataset

The project uses a relational database containing six primary tables:

| Table                         | Description                               |
| ----------------------------- | ----------------------------------------- |
| `dim_customer`                | Customer and market information           |
| `dim_product`                 | Product, segment and division information |
| `fact_gross_price`            | Gross price information                   |
| `fact_manufacturing_cost`     | Manufacturing cost information            |
| `fact_pre_invoice_deductions` | Pre-invoice deduction information         |
| `fact_sales_monthly`          | Monthly sales transactions                |
